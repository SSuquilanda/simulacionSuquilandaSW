# Simulación Apellido

Este proyecto permite consultar datos de consumo y deudas pendientes de energía eléctrica.

## 📂 Estructura del Proyecto
Esta dividido en 2 ramas, cada una para fronted y backend
- **`backend/`** → Código del backend en Jakarta EE.
- **`frontend/`** → Código del frontend en Angular.

## 🚀 Tecnologías Utilizadas
- Backend: Jakarta EE, WildFly, MySQL/PostgreSQL
- Frontend: Angular, TypeScript
- Base de Datos: Simulada o real con MySQL/PostgreSQL
